# Инструкция по установке сборки DrakanHex9
### Дисклеймер
- Тыкайте по синему тексту, чтобы перейти.
- Адресс сервера включён в игру по умолчанию.
- **Для работы автообновления нужен доступ к GitHub, Modrinth и CurseForge.**
- Для обхода DPI, если он у вас ещё не стоит, советую установить [`zapret`](<https://github.com/Flowseal/zapret-discord-youtube>)
  - Пожалуйста, следуйте инструкциям по установке на сайте.
  - **если не работает, придётся открывать с VPN, например Cloudflare One Client.**

### После установки обхода необходимо иметь Prism Launcher.
- Устанавливаем [Prism Launcher](<https://prismlauncher.org>) или его [пиратского аналога](<https://elyprismlauncher.github.io>).
- Скачиваем [DrakanHex-9-client.zip](https://github.com/alexyzer/DrakanHex/archive/9/client.zip), перетаскиваем в окно лаунчера (читайте до конца).
- Если используете [PineconeMC](<https://elyprismlauncher.github.io>), необходимо отключить систему скинов ely.by для профиля.
  - `Изменить` -> `Параметры`
  - Вытавить галочку `Ely.by patch`
  - Установить `Download and apply Ely.by game patch` на `Never`
- После того, как все шаги соблюдены, запустите сборку.
  - Будет предложен список опциональных модов, выберите что вам нужно.
